# iQlinic Landing Page

Premium bilingual (Persian/English) landing page for the iQlinic Clinical Intelligence Layer.

## Run

Open `index.html` directly, or serve the folder with any static server:

```powershell
npx serve .
```

The website has no build step or runtime dependencies. Language preference is stored locally in the browser.

## Deploy to Vercel

Import the GitHub repository in Vercel and keep the framework preset as `Other`. No build command or output directory is required.
